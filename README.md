## SecureCrypt Quick Start

```bash
cd 2601240007_CTP_Project
python -m venv .venv
```

Activate the environment, then install dependencies and launch:

```bash
pip install -r requirements.txt
python run_cli.py
```

See the [SecureCrypt project README](./2601240007_CTP_Project/README.md) for setup, GUI usage, tests, project structure, and security notes.
