# 260124007-Mtech-CPT LAB

This folder contains the **13 Python CPT exercises** shown in the exercise list.

## Program Structure

| Program | Topic |
|---|---|
| 1 | Implement Divide-and-Conquer algorithms for Merge Sort and calculate their time complexities |
| 2 | Implement Dynamic Programming for 0/1 Knapsack and analyze time and space complexity |
| 3 | Develop a reusable Python package implementing Stack and Queue using type hints and dataclasses |
| 4 | Compare list-based processing and generator-based processing for a large dataset in execution time and memory usage |
| 5 | Develop a Banking Management System demonstrating inheritance and abstraction with full type hints |
| 6 | Implement a Student/Employee data model using dataclasses and compare it with a traditional class implementation |
| 7 | Develop a Producer-Consumer application using threading, multiprocessing and synchronization primitives |
| 8 | Develop an asynchronous web crawler using asyncio, aiohttp and retries and compare it against a sequential implementation |
| 9 | Write comprehensive unit and integration tests for a Python application using Pytest and Hypothesis |
| 10 | Configure mypy, Docker and GitHub Actions CI/CD for an existing Python project |
| 11 | Develop a Python application using GitHub Copilot/Cursor/Claude Code with specification-first development and document AI assistance |
| 12 | Perform AI-assisted code review, refactoring and testing, documenting where AI succeeded and where manual intervention was required |
| 13 | Implement specification-first, type-driven and test-first development with AI |

Each program contains:
- `Program_1.py`-style Python source file
- `README.md` with problem statement, concept identification, example, procedure, implementation, input/output, analysis and conclusion.

## Execution

Run an individual program with:

~~~bash
python Program_N.py
~~~

Replace `N` with the required program number.

## Note

The exercise list supplied for this lab is used as the basis for the problem statements and implementations.
