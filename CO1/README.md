## Programs

| No. | Program | Core Concept |
|---:|---|---|
| 1 | University Library Book Lookup | Binary Search |
| 2 | Student Marks Ranking | Merge Sort |
| 3 | Car Parking Management | Dictionary / Searching |
| 4 | Student Attendance Analysis | Lists / Iteration |
| 5 | Online Shopping Cart | Lists / Calculation |
| 6 | Delivery Order Distance Management | Quick Sort |
| 7 | Closest Pair of Coins | Closest Pair |
| 8 | Maximum Profit Streak | Maximum Subarray / Kadane's Algorithm |

## How to Run

Open a terminal inside the required program folder and run:

```bash
python ProgramFileName.py
```

Example:

```bash
cd 06_QuickSort_DeliveryOrders
python QuickSort_DeliveryOrders.py
```

## Requirements

- Python 3.x
- No external libraries are required.

## Academic Note

The first five programs cover the examples discussed in the lab material. The final three use separate real-world scenarios for Quick Sort, Closest Pair, and Maximum Subarray as requested for the remaining practical exercises.
